Description

XR Collaboration Proto2 is a multi-user extended reality research prototype built in Unity. It provides a shared virtual environment where multiple participants can collaborate in real time, interact with physics-based objects (a Jenga block tower), and communicate through avatars.

The prototype supports hand tracking with three interaction modalities — pinch, poke, and ray — via OpenXR. Eye tracking is integrated with gaze data logging to CSV files, enabling behavioral research on attention and collaboration patterns in XR. The system targets the HTC Vive Focus Vision standalone headset using Unity 2022.3 LTS.
