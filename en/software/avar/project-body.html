Description

AVAR (AVAR2) is a spatial data visualization application for Apple platforms (visionOS 2.0+ and iOS 18+) that renders graph data — nodes and edges described in JSON — as interactive 3D objects anchored in augmented reality. Nodes are represented as 3D geometric shapes (boxes, spheres, cylinders, cones) and can be dragged, scaled, and snapped to real-world surfaces such as walls, floors, tables, and ceilings detected by ARKit.

The app accepts graph data from three sources: bundled example files, direct JSON paste, or real-time injection via an embedded HTTP server (port 8081) that accepts POST requests to /avar. This makes AVAR a live AR visualization frontend for external tools such as Pharo Smalltalk. Multi-user collaborative sessions are supported via SharePlay (GroupActivities), allowing synchronized spatial AR diagrams across devices.
