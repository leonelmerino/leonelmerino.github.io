Pace Cast

Repositorio GitHub

Descripción

Pace Cast es una prueba de concepto que utiliza un HTC VIVE Ultimate Tracker colocado en el pie como sensor de marcha para controlar en tiempo real la velocidad de reproducción de un video en primera persona. Caminar en el lugar aumenta la tasa de reproducción del video mientras se preserva el tono de audio, creando un acoplamiento perceptual entre el movimiento físico y la locomoción visual.

El sistema consiste en un backend Python que lee datos del tracker via SteamVR y un frontend web (en un navegador basado en Chromium) que recibe comandos de velocidad y ajusta el video correspondiente. Este POC explora la interacción corpórea para navegación virtual y experiencias de medios inmersivos.
