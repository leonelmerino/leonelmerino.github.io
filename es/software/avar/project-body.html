Descripción

AVAR (AVAR2) es una aplicación de visualización de datos espaciales para plataformas Apple (visionOS 2.0+ e iOS 18+). Renderiza datos — estructurados como nodos y aristas en JSON — como objetos 3D interactivos anclados en realidad aumentada. Los nodos aparecen como formas geométricas (cajas, esferas, cilindros, conos) que pueden arrastrarse, escalarse y ajustarse a superficies del mundo real como paredes, pisos, mesas y techos detectados por ARKit.

La app acepta datos desde tres fuentes: archivos de ejemplo incluidos, pegado directo de JSON, o inyección en tiempo real mediante un servidor HTTP embebido (puerto 8081) que acepta solicitudes POST a /avar. Esto convierte a AVAR en un frontend de visualización AR en vivo para herramientas externas como Pharo Smalltalk. Las sesiones colaborativas multiusuario se soportan mediante SharePlay (GroupActivities), permitiendo diagramas AR sincronizados entre dispositivos.
